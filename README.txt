# Instructions to Run the Project

## 1. Install Required Packages

First, make sure you have Python and Jupyter Notebook installed. Then, create a virtual environment (optional but recommended):

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

Then, install the required packages:

```bash
pip install -r requirements.txt
```

## 2. Run the Jupyter Notebook

Make sure train.csv, test.csv, and prediction file is in the same directory as the Jupyter Notebook. Start Jupyter Notebook with the following command:

```bash
jupyter notebook
```

Then, open the `.ipynb` file from the Jupyter interface.
